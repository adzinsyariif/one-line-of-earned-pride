A program that writes one line of text — a quiet, earned moment of pride — to `/output/entry.txt`, for the [One Line of Earned Pride](https://make.fun/bounty/u-mang-one-line-of-earned-pride-a0138557) bounty on make.fun.

## The line

> Last spring he couldn't read the menu; tonight he reads the specials aloud to his grandmother, slowly, without stopping once.

A small person doing something hard: a boy who couldn't read last spring now reads aloud to his grandmother. The effort is felt in the contrast, and the pride lands on the last word.

## Run

```sh
node main.ts
```

Requires Node 22 or later. Deterministic, standard library only — the same line on every run.
